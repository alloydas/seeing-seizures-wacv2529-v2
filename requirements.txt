# ── Deep learning ─────────────────────────────────────────────────────────
# torch 2.4.0 <-> torchvision 0.19.0 is the only valid pairing here (both cu121).
#   FLOOR   torch>=2.4  every trainer uses torch.amp.GradScaler("cuda") and
#                       torch.autocast("cuda", ...).
#   CEILING torch<=2.5  sweep_session.py calls torch.load() without
#                       weights_only=; torch 2.6 flipped that default to True
#                       and raises UnpicklingError on these checkpoints.
